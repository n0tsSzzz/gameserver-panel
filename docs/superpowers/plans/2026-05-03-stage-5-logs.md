# Stage 5 — Logs (tail + SSE) — Implementation Plan

> Inline execution. Spec: `docs/superpowers/specs/2026-05-03-stage-5-logs-design.md`. Branch: `stage-5-logs`.

**Goal:** Add tail and SSE-stream log endpoints; node-agent publishes to Redis pub/sub; API subscribes.

**Tech Stack:** redis-py async, fakeredis for tests, FastAPI StreamingResponse, JWT for one-shot stream tokens.

---

## Task groupings (each lands as a single commit after `make lint typecheck test`)

### Group 1: node-agent — Redis client + LogPublisher + create/delete hookup
- `apps/node_agent/pyproject.toml`: add `redis>=5,<6`.
- `core/config.py`: add `redis_url: str = "redis://localhost:6379"`.
- `log_publisher.py`: class with `start`/`stop`/`shutdown`/`_run` (async, dict[cid, Task]).
- `domain/containers.py`: `ContainerService.__init__` takes optional publisher; `create` calls `publisher.start(out.id)`, `delete` calls `publisher.stop(container_id)` before facade.remove.
- `api/containers.py`: `_service` builds `ContainerService(facade, publisher)` from app state.
- `main.py`: lifespan creates publisher, exposes `app.state.log_publisher`; cleanup on shutdown.
- Tests: `test_log_publisher.py` using **fakeredis** (`fakeredis.aioredis.FakeRedis`), 4 cases: start_publishes / start_idempotent / stop_cancels / shutdown_cancels_all.

### Group 2: node-agent — `tail_logs` facade + `GET /logs?tail=N` endpoint
- `docker_facade.py:DockerFacade.tail_logs(container_id, n) -> list[str]`.
- `domain/containers.py:ContainerService.tail_logs(container_id, n)` with mapping.
- `schemas/containers.py`: `LogsTailOut`.
- `api/containers.py`: `GET /containers/{id}/logs?tail=N` (Query 1..10000), drop old `/logs/stream` route.
- Tests: extend `test_containers_routes_mock.py` with tail tests; remove old SSE route test.

### Group 3: API — Redis pool + JWT log tokens
- `apps/api/pyproject.toml`: add `redis>=5,<6`, `fakeredis>=2.26,<3` (dev).
- `core/config.py`: `log_stream_token_ttl_s: int = 60`.
- `core/security.py`: append `create_logs_stream_token`, `decode_logs_stream_token`.
- `tasks/redis_pool.py`: `create_redis_pool(url) -> aioredis.Redis`.
- `main.py` lifespan: create `app.state.redis`, close on shutdown.
- Tests: `test_security_logs_token.py` (create+decode roundtrip; expired raises; wrong type raises).

### Group 4: API — node-agent client (tail) + ServerService + endpoints
- `apps/api/src/gamehost_api/clients/__init__.py` empty.
- `clients/node_agent_client.py`: `NodeAgentClient(node, timeout_s)`, `tail_logs(cid, n) -> list[str]`.
- `domain/servers.py`: add `get_log_tail`, `mint_log_token`, `stream_logs_iter` to `ServerService` (constructor takes redis client).
- `api/v1/servers.py`: 3 new endpoints (`GET /logs?tail`, `POST /logs/stream-token`, `GET /logs/stream?t=...`).
- Tests: `test_server_logs_routes.py` covering auth, ownership, happy tail (respx-mocked node-agent), token mint, stream w/ fakeredis publish.

### Group 5: README + final pipeline + push
- README "Stage 5: logs" with curl + JS EventSource sample.
- `make lint typecheck test`; push.
